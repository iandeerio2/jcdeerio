Common Deployment Fixes

Troubleshooting Guide

Images & Paths

Broken Relative Image Paths

  • • Verify exact file names and extensions (case-sensitive on Linux/GitHub Pages: stage.jpg vs STAGE.JPG).
  • • Use relative paths like ./images/mati-2026.jpg instead of local PC paths (C:\... or Google Drive viewer links).
  • • Ensure image files are uploaded alongside index.html.
Security & Links

HTTPS & Mixed Content

  • • Enable Enforce HTTPS in GitHub Pages or SSL/TLS in cPanel/Netlify.
  • • Replace any http:// script, font, or media URLs with https:// to prevent browser blocks.
Updates & CDN

Stale Browser or CDN Caching

  • • Do a hard refresh (Ctrl+F5 or Cmd+Shift+R) after uploading new changes.
  • • Add a query version when updating files (e.g., portrait.jpg?v=2) or clear CDN/hosting cache.
